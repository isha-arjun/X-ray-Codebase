Analysis boundaries

Dependencies are recognized with conservative pattern matching for JavaScript, HTML, and CSS. This is not a full language parser; dynamic paths, aliases, framework magic, and unsupported syntax may be missed. Source code is displayed as text and never executed.

Ignored by default: .git, node_modules, dist, build, coverage, and .next. Limits: 2,000 files, 1 MiB per readable file, and 20 MiB total readable content. Unsupported binary/large files are listed in the report but not previewed. Browser extensions and the browser environment itself are outside this app's control.
