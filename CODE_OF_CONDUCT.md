# Code of Conduct

We want Codebase X-Ray to be a welcoming, constructive project.

## Expected behavior

- Be respectful, patient, and specific in technical feedback.
- Assume good intent while addressing the impact of behavior.
- Welcome people with different backgrounds, experience levels, and communication styles.
- Give actionable criticism without personal attacks.
- Respect privacy and avoid sharing another person's code or personal information without permission.

## Unacceptable behavior

Harassment, threats, discriminatory language, deliberate intimidation, doxxing, sexual harassment, and sustained disruptive behavior are not acceptable.

## Maintainers

Project maintainers may edit, reject, or remove contributions that violate these expectations. If you experience or witness unacceptable behavior, contact a maintainer privately through the repository's available GitHub contact mechanisms. Do not publish sensitive details in a public issue.
